# ClassBoard · 课程表 Web 应用

跑在 NAS Docker 上的自托管课程表应用，适配电脑与手机浏览器。课程数据以 PDF 导入为主（正方教务系统导出的课表 PDF，前端解析）、手动录入为辅；单用户家庭使用；支持课程提醒、考试与作业记录、数据导出备份。

## 文档阅读顺序

1. 先读 PRD，理解产品要做什么（功能、边界、验收标准）。
2. 再读技术设计文档，了解系统如何架构（接口契约、数据模型、Docker 部署）。
3. 前端与设计侧继续阅读设计语言文档与 UI 设计文档，落地时以组件参考 HTML 为视觉基准。

## 技术栈概览（详见技术设计文档）

- 后端：Node.js（node:22-alpine）+ Express + better-sqlite3（SQLite WAL）
- 前端：Vue 3 + Vite，构建产物由同一容器静态托管，同源 `/api`
- 部署：单容器 Docker，数据持久化到挂载卷 `/app/data`，支持 x86 与 ARM；已部署至 NAS 192.168.10.110:3005（`CLASSBOARD_PORT` 可配，3000/3001 被占用时改端口）

## 视觉选型

已确定视觉方向为**清新浅色极简**（风格预览 01）：近白背景、单一主蓝点缀、浅底描边课程色块、柔和分层阴影，本期不做暗色模式。设计语言文档 v2.0 为此体系的唯一权威来源，UI 设计文档与组件参考 HTML 均已对齐。

6 种候选风格的对比示例保留在 `examples/style-preview/`，供日后切换或参考。
