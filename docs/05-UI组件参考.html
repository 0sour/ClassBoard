输入控件

Input 输入框

格式不正确，示例：第 1-16 周

Select / Switch / 日期

AppSelect 尺寸：sm 32px（顶栏内嵌）/ md 40px（表单，本示例）；触发器 role="combobox" + aria-expanded，点击外部关闭（文档级 mousedown 监听，无遮罩）。

颜色选择一律使用课程色板色卡（选中描边 --color-border-focus 圆环）；不使用原生 select（文档 4.9 禁用）。

一二三四五六日

时间选择 TimePicker（v2.4 补全）

自研时间选择（文档 4.10）：不用原生 time / datetime-local。触发器 + 小时/分钟双列滚动面板，5 分钟步进；sm 32px（卡片内嵌）/ md 40px（表单）；点击外部关闭（文档级 mousedown）

sm（设置页节次模板）与 md（考试/作业表单）
:

小时列 00–23、分钟列 00/05/…/55；选中项 brand-subtle 底 + brand 字；打开时选中项自动滚动到列中央；节次模板保存时校验时间冲突（相邻首尾相接允许）。

07

弹层

桌面居中弹窗 Modal

白底 radius-xl + shadow-pop；遮罩 rgba(15,23,42,.42) + blur(4px)。窗口收窄到 768px 以下自动切换为底部弹层形态。

移动端底部弹层 BottomSheet

自底部滑入、顶部圆角与拖拽柄，常用于移动端操作菜单。

反馈

Toast 轻提示

白底 + shadow-pop + 语义色左条，自动消失，支持成功 / 警告 / 错误 / 信息四类

确认对话框 Confirm

复用弹层组件，危险操作二次确认，确认后触发对应反馈

骨架屏 Skeleton

bg-subtle 浅底呼吸占位，无内容加载时提供稳定布局

错误态 ErrorState（v2.2 补全）

三态表现之错误态：--color-feedback-error 文字图标 + 重试按钮，网格/列表整体替换（04 文档 3.1）

网络异常，请检查后端服务后重试。

图标按钮状态（v2.2 补全）
