## 1. 需求背景

班级课表长期靠「截图 + 群公告」传播：教务系统一改课（调课、调休、补课），截图就过期，同学问、班长改，反复来回。现成课程表 App 要每个同学各自导入、各自注册，且数据在别人云上。

ClassBoard 把这件事做成**发布与订阅**：班级负责人维护一份权威的班级课表（含学期日历与单课调整），发布在 NAS 上的一个公开地址；同学打开链接就能看，不需要账号、不需要安装、不会看到过期截图。课表数据留在班级自己的 NAS 上。

不做的前提：不追求全网课表社交，不做课程评分/表白墙等社区功能；不代同学做个人课表（只发布班级课表）；不接入学校教务接口（课表以 PDF 导入 + 手动维护为主）。

## 2. 目标与成功指标

| 目标 | 衡量方式 |
|------|----------|
| 负责人能快速发布班级课表 | 从拿到教务 PDF 到公开页可访问 ≤ 15 分钟（导入 → 核对 → 发布） |
| 同学零门槛查看 | 公开页免登录、免安装，手机打开即见今日与本周课表，可加入主屏 |
| 课表始终与教务一致 | 调休、停课、调课、补课都在课表上看得见（角标 + 原位置标记 + 调整链），不需要另发通知解释 |
| 多人共管不打架 | 一个班可有多个负责人（同级），任何改动都记入变更记录，可单条撤销或整班回退 |
| 数据不丢失、可搬走 | 本地库 + 自动快照 + 账号导出 JSON；管理员可整站导出 |

## 3. 用户与场景

| 角色 | 说明 | 主要入口 |
|------|------|----------|
| 平台管理员 | 部署 NAS、审批注册申请、管理账号与班级。通常也是某个班的负责人 | 后台 `/login` → 设置（审批 / 用户管理 / 班级 / 数据） |
| 班级负责人（班长 / 学委） | 维护本班学期、节次、课表、日历与调整，发布通知，公示作业与考试 | 后台 `/week`、`/day`、`/settings` |
| 浏览者（同学） | 只看，不登录 | 公开 `/`（班级选择）与 `/class/:id`（班级课表 + 通知 + 公示） |

核心场景：

1. **P0 首次建班发布**：注册 → 管理员审批 → 建班（学校 + 班级名，同名即同一个班，可加入成为共同负责人）→ 建学期与节次 → 导入教务 PDF → 公开页可访问。
2. **P0 同学查看**：打开公开地址 → 班级课表（周课表 / 今天）→ 看到今天的课、本周课表、班级通知、作业与考试公示。
3. **P0 调课调休**：国庆调休、老师出差停课、临时调课、补课——登在课表上，同学无需额外通知即可看懂；调整可撤销。
4. **P1 发布通知**：负责人手写通知（可置顶、可关联课程），同学在公开页铃铛里读。
5. **P1 公示作业与考试**：负责人登记截止时间 / 考试时间，同学在课表侧栏看「待交 / 已截止」与「即将进行 / 已结束」。
6. **P1 多人共管**：同班两名负责人各自维护，互不覆盖；每次改动可在变更记录里看到是谁改的。
7. **P2 出错了要能回退**：改错了课程或误删了数据 → 变更记录里单条撤销；大范围改错 → 整班回退到某个时刻。
8. **P2 数据搬家**：换 NAS 或另建一个班 → 导出 JSON 再导入（作为新班级 / 覆盖已有班级）。

## 4. 竞品简析

| 竞品 | 形态 | 与本产品的差异 |
|------|------|----------------|
| 超级课程表 / 课程格子 | 手机 App，云端账号 | 每个同学各自导入、数据在云端；无法承载「班级一份权威课表」 |
| 教务系统网页 | 校内系统 | 只有原始课表，没有调课/调休/通知的发布位；校外访问常受限 |
| 班级群里的课表截图 | 图片 | 会过期、不可检索、不能切换周次；调课信息靠翻聊天记录 |
| 自建日历 | 通用日历 | 无法表达节次、单双周、调休与单课调整 |

结论：本产品以「**班级一份权威课表 + 免登录公开页 + 自托管**」为核心差异化，兼顾「多人共管 + 变更可追溯」。

## 5. 功能需求

### 5.1 功能总览

| # | 模块 | 功能描述 | 可见对象 |
|---|------|----------|----------|
| 1 | 公开面 | 班级选择面板（按学校 / 班级名搜索）与班级课表页（周课表 / 今天、班级通知、作业与考试公示），免登录只读 | 所有人 |
| 2 | 账号 | 注册申请（学校 / 专业 / 想加入的班级）→ 管理员审批（通过 / 拒绝带理由）；登录 / 退出 / 记住设备 / 修改密码 / 已登录设备管理 | 负责人、管理员 |
| 3 | 班级 | 创建（学校 + 班级名为唯一标识）、同名加入（成为共同负责人，权限同级）、班级资料（学校 / 班级名 / 专业 / 城市）、退出与删班（最后一人退出即删班，可回退） | 负责人 |
| 4 | 学期与节次 | 班内多个学期，各自起止日期、每周起始日与节次时间模板（默认 12 节含晚自习，可增删） | 负责人 |
| 5 | 课表 | 周视图（7 列 × 节次行，周导航，单双周过滤，冲突分栏，打印 / 导出 PNG）与今天页；课程含类型（普通 / 实验）、教师、地点、颜色、周次、星期、起止节次、备注 | 负责人（可编辑）/ 所有人（只读） |
| 6 | 课表导入 | ① 从教务 PDF 导入（前端解析，预览校验，追加 / 覆盖两种模式）；② 手动录入（可连续录入多门） | 负责人 |
| 7 | 学期日历 | 日期级规则：**放假**（可区间录入）与**调休（整日移课：某天的课整批移到另一天）**；日头角标「假期 / 调休 / 补 X 月 X 日」 | 负责人维护，所有人可见 |
| 8 | 单课调整 | 停课 / 调课 / 补课；课表长按拖拽即登记调课；原位置留淡显标记，调整链可展开查看，可逐站撤销 | 负责人维护，所有人可见 |
| 9 | 调整台账 | 设置 → 日历：整日规则 + 单课调整列表 + 「＋ 登记调整」 | 负责人 |
| 10 | 通知 | 班级通知：日期（排序键）、标题、正文、可关联课程、可置顶；公开页与后台共用同一条时间线 | 负责人发布，所有人可读 |
| 11 | 作业与考试 | 班级公示：作业（截止时间）与考试（时间 / 地点），可关联课程；学生看「待交 / 已截止」「即将进行 / 已结束」 | 负责人维护，所有人可读 |
| 12 | 变更记录与回退 | 每次写操作留痕（谁 / 何时 / 改了什么，字段级 diff）；单条撤销；整班回退到某个时刻；课程与通知有独立「历史」入口；管理员可看全站 | 负责人（本班）、管理员（全站） |
| 13 | 导入导出 | 按账号导出（名下全部班级）；管理员整站导出（含账号与口令哈希）；导入两种模式（作为新班级 / 覆盖已有班级），旧版 v2–v5 备份自动翻译 | 负责人 / 管理员 |
| 14 | 外观 | 固定清新浅色；中文；PWA 可添加到主屏幕 | 所有人 |

**已下线（v2.0 起不再提供）**：课程提醒与实验课提醒（含浏览器通知与站内提醒列表）、事项页（考试 / 实验 / 作业三个子 Tab，改为课表侧栏的公示卡）、访问口令（由账号体系取代）、课程模板（组合模板 / 另存模板）。

### 5.2 公开面

**班级选择面板（P0）**：`/`。按学校 / 班级名搜索已发布的班级，列出班级名、学校、学期数与更新时间；点入班级课表页。空态引导「如果你的班还没发布，请联系负责人」。

**班级课表页（P0）**：`/class/:id`。结构与后台周课表一页不差（同一套组件）：顶部品牌 + 周课表 / 今天 分段 + 班级通知铃铛 + 学期切换 + 「后台登录」；桌面为周网格 + 右侧信息栏，手机为日期轮盘 + 当天列表 + 底部两标签。所有角标、日头胶囊、原位置标记、调整详情卡都与后台一致；点课程只看详情，**没有任何编辑入口**。

### 5.3 账号与班级

- **注册**：后台登录页提供不显眼的注册入口；填写用户名 / 密码（6–64 位）/ 学校 / 专业 / 班级名。注册开关由管理员控制，默认关闭。
- **审批**：管理员在设置 → 审批 中通过或拒绝（可填理由）；待审核 / 被拒状态在登录页可见。未通过审核不能建班。
- **建班与加入**：学校 + 班级名是唯一标识；同名建班返回「已存在」，可一键加入成为**共同负责人**（同级，无 owner 概念）。
- **班级资料**：学校 / 班级名 / 专业 / 城市（城市用于该班天气卡）。
- **退出与删班**：任一负责人可退出；最后一人退出即删班（连同数据）。删班与退出都记入变更记录（class_id 为空，管理员在全站视图可见）。
- **账号管理（管理员）**：创建账号、修改角色、禁用、重置密码、删除（删除会连带其班级，若该班无其他负责人）。

### 5.4 学期与节次

- 班内可建多个学期，各自起止日期、每周起始日（周一 / 周日）与节次模板；当前学期可切换（顶栏与设置）。
- 节次模板默认 12 节（08:00–22:30 含晚自习），可增删改时间；删除节次会连带移除该节次上的课程时间并把后续节次前移（按整班记录，可回退）。
- 周次按学期起始日与每周起始日推算；超出范围显示未开学 / 假期。

### 5.5 课表

**周视图（P0）**：左列节次时间，右侧 7 列周一至周日（桌面）或单日（手机）。顶部周导航（上一周 / 第 N 周 · 日期区间 / 下一周 / 回到本周）与单双周徽标。点课程看详情；空白格点击快捷新增；桌面长按拖拽登记调课；打印与导出 PNG。

**今天页（P0）**：当天课程卡片（时间、课名、地点教师、节次）+ 当日提示条（放假 / 调休 / 有课是调过来的 / 有课停课或调走）+ 今日课程的作业 + 移动端天气卡。

**课程字段**：名称（1–50）、类型（普通 / 实验，实验带「实验」标记）、教师、地点、颜色（8 色轮询，可改）、周次（全部 / 单 / 双 / 自定义）、星期、起止节次、备注。

**冲突**：同一时间两门课按 1/3⇄2/3 动态分栏显示，色块带冲突圆点；不拦截保存。

**角标（P1）**：按类型固定语义色的全胶囊——调课（蓝）、补课（绿）、调休（紫）、停课（红）、多次调整（靛蓝），链上 ≥2 站追加「多次调整」；点角标打开调整详情卡。日头胶囊同族配色，假期为中性虚线。

### 5.6 课表导入

- **从教务 PDF 导入**：上传正方教务系统导出的课表 PDF，前端解析（表头「时间段 | 节次 | 星期一~星期日」，单元格以 `/` 分隔、`:` 键值），预览校验后导入到指定学期；模式为追加或覆盖（覆盖仅清空该学期课程，考试与作业保留但关联置空）。
- **手动录入**：课程编辑弹窗逐门填写，保存后可「继续新增下一门」。
- 解析规则详见《技术设计文档》「PDF 解析」一节；实验课一律手动录入，PDF 里的实验学时信息保留在备注。

### 5.7 学期日历（放假 / 调休）

- **放假**：该日不上课，支持区间录入（如 10 月 1–8 日），可附备注。
- **调休（整日移课）**：把某一天的课**整批**移到另一天。源日显示为调休（原位置留「已移至 …」），目标日显示源日当天的课。
- **不假设课表每周重复**：跳周课程按源日所在周的安排原样搬走。
- **写入期校验**：同一学期内移课**目标日唯一**（多源指同一天会被拒绝并指名冲突），且**不允许成环**（A→B→…→A 会被拒绝）。
- 链式调休（A→B→C）合法：中间站留「经此」标记，块只出现在终到的日期。

### 5.8 单课调整（停课 / 调课 / 补课）

- **停课**：这一次不上。
- **调课**：某一天的课改到另一天的指定节次（可跨周、可改节次）。
- **补课**：在指定日期额外上一次（可填地点与备注）。
- **叠加语义（P0）**：「先调休、再调课」与「先调课、再调休」都能算对——课只出现在**终到日**，基准日与中间站留淡显标记，链上 ≥2 站显示「多次调整」。调整按「来源发生（当前所在日期 + 节次集合）」匹配，不比对星期。
- **登记入口**：课表长按拖拽（调课）、课程详情「调整」Tab、设置 → 日历台账「＋ 登记调整」（原日期从这一天实际发生的课里挑，因此链式调整后的课也能继续调整）。
- **撤销**：单课调整可逐站撤销（撤销到上一站）；整日调休要在台账的规则列表里清除。

### 5.9 通知

- 负责人手写：日期（排序键，默认今天）、标题、正文、可关联课程、可置顶。
- 排序：置顶优先，其余按日期倒序；一条都不隐藏。
- 位置：后台顶栏铃铛（角标 = 通知总条数）；公开页铃铛读同一份，只读。
- 每条通知有「历史」入口（变更时间线）。

### 5.10 作业与考试公示

- 作业：名称、截止时间（必填）、关联课程（可选）、备注；考试：名称、时间、地点、关联课程、备注。
- 学生视角：课表右侧栏「作业 / 考试」卡；作业分「待交 / 已截止」，考试分「即将进行 / 已结束」。负责人可在卡内直接增删改。
- 不再有个人完成状态：作业是班级公示信息，不是个人待办。

### 5.11 变更记录与回退

- 每一次写操作留一条记录：谁、什么时候、动了什么（字段级 diff，中文标签）。
- **单条撤销**：把该对象恢复成改动之前的样子（追加一条「撤销」记录，不截断历史）。若此后同一对象又被改过（且那一下现在还生效），服务端返回冲突并列出明细，界面提示「按时间从新到旧逐条撤销，或用整班回退」。
- **整班回退**：把班级整体回到某条记录那一刻（学期 / 课表 / 日历 / 调整 / 通知一起回退），会丢掉其后的改动（记录仍保留），随后写一条「整班回退」。
- 入口：设置 → 变更记录（按类型 / 只看我筛选；管理员多一个「全站」视角，可按班级与操作人筛选）；课程详情「历史」；每条通知「历史」。
- 边界：老库在启用变更记录之前的早期记录没有整班快照，回退不到那么早（明确报错，不会清空班级）。

### 5.12 导入导出

- **按账号导出**：名下全部班级（班级资料、学期、课程、日历、调整、通知、作业、考试），天气密钥脱敏写入。
- **整站导出（管理员）**：全部班级 + 全部账号（含口令哈希，可直接重建登录），文件内标注「含口令哈希」。
- **导入**：两种模式——**作为新班级**（填写学校 + 班级名；多班备份按备份里的班级逐个新建，重名自动加「（导入）」后缀）与**覆盖已有班级**（清空所选班级后重建，可整班回退）。旧版 v2–v5 备份自动翻译（旧课程结构升级、缺日历与调整按空处理、没有班级字段的落到目标班级）。

### 5.13 设置

Tab 分区：班级 / 学期 / 节次 / 日历（台账）/ 变更记录 / 显示 / 天气（管理员）/ 数据 / 账号 / 审批（管理员）/ 用户管理（管理员）。

- **显示**：单双周过滤开关（关闭时显示全部课程）。
- **天气**：和风天气 Key（管理员配置，全站共享；城市在班级资料里），数据经服务端代理隐藏 Key，30 分钟缓存。
- **账号**：改密码、查看与撤销已登录设备。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 响应式 | 手机竖屏（≥360px）/ 平板 / 桌面（≥1280px）功能完整；公开页与后台在两端一致 |
| 性能 | 首屏可交互 ≤ 2s（本地网络）；课表解析（前端）≤ 300ms；PDF 解析 ≤ 3s |
| 部署 | Dockerfile + docker-compose；x86 / ARM 均可；数据落挂载卷；端口与时区可配；带构建期镜像源参数（受限网络可用） |
| 数据安全 | 数据只在班级自己的 NAS 上；口令 scrypt 哈希；备份导出可选、整站导出标注入内容；每次部署前自动备份 data/*.db* |
| 可追溯 | 所有写操作进变更记录；撤销与回退不截断历史 |
| 浏览器兼容 | Chrome / Edge / Safari 最近两个大版本 |
| PWA | Manifest + 图标，可添加到主屏幕；不做离线缓存 |

## 8. 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|

## 9. 验收标准

| # | 场景 | 通过标准 |
|---|------|----------|
| 1 | 建班发布 | 注册 → 审批 → 建班 → 建学期 → 导入 PDF → 公开页可访问，同学无需登录即可看本周与今天 |
| 2 | 同名共管 | 第二位负责人加入同名班级后，两人都可编辑，变更记录里能区分操作人 |
| 3 | 调休 + 调课叠加 | 「9/30 的课移 10/17，再调到 10/13」后：10/13 显示该课并带「调课 + 多次调整」角标，10/17 与 9/30 留淡显标记，调整卡按「基准 → 调休 → 调课 → 终到」展示 |
| 4 | 写入期校验 | 目标日已被占用的移课、以及会成环的移课，都返回明确拒绝且不改数据 |
| 5 | 通知与公示 | 负责人发布通知 / 作业 / 考试后，公开页铃铛与侧栏立即可见，且无任何编辑入口 |
| 6 | 撤销与回退 | 单条撤销把对象恢复原状并留下「撤销」记录；后改过的对象撤销时给出冲突明细；整班回退后班级数据回到那一刻 |
| 7 | 导入导出 | 账号导出可再导入为新班级；覆盖导入只影响所选班级；v2–v5 旧备份可导入且不再复活已下线的提醒设置 |
| 8 | 公开面不泄露 | 公开接口与页面不含账号、设置、天气密钥；只读页无编辑入口 |
| 9 | 部署 | 按部署脚本执行后容器健康、数据落卷、重启不丢；部署前自动备份数据库 |
