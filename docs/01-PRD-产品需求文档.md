## 1. 需求背景

家庭场景中，学生的课程安排分散在教务系统、家长群、纸质课表等多处。家长需要在电脑和手机上随时查看孩子的课程、考试与作业，但目前没有一款既能自托管、又免注册的轻量工具。主流课程表 App（如超级课程表、课程格子）依赖账号体系与云端服务，数据不出家门是家庭用户的硬性诉求。

NAS 已成为家庭数据自托管的主流载体，且已支持 Docker。把课程表做成一个跑在 NAS 上的自托管 Web 应用，数据落本地、电脑手机通用，是解决上述问题最直接的形态。

不做的前提：本产品面向单用户家庭使用，不提供多账号体系；课程数据以导入为主（正方教务系统导出的 PDF 课表）、手动微调为辅。

## 2. 目标与成功指标

| 目标 | 衡量方式 |
|------|----------|
| 一周内能完成录入并投入使用 | 用户通过「上传教务系统导出的 PDF 课表 → 自动解析 → 预览校验 → 确认导入」完成首次课程导入，全程不超过 15 分钟 |
| 电脑与手机访问体验一致 | 手机（竖屏）默认日视图、电脑默认周视图，关键操作（查看/新增/编辑课程）在两端均可完成 |
| 数据不丢失 | 所有数据存储在本地持久化卷；提供一键导出 JSON 备份 |
| 提醒及时可用 | 课程提醒在设定时间触发浏览器通知，成功率达 100%（浏览器允许通知前提下） |

## 3. 用户与场景

| 角色 | 说明 |
|------|------|
| 家庭管理员（主要用户） | 部署 NAS、导入课表、维护课程与考试作业信息。电脑为主、手机为辅 |
| 家庭浏览者（次要用户） | 通过手机随时查看当天课程、考试与作业。只读为主 |

核心场景，按优先级排序：

1. **P0 导入课表**：上传教务系统导出的 PDF 课表 → 自动解析 → 预览校验 → 确认导入。
2. **P0 查看课表**：打开即见本周课表；切换周次、单双周过滤；点击课程查看详情。
3. **P0 当天安排**：手机上快速查看今天的课程、考试、作业。
4. **P1 课程提醒**：上课前 N 分钟收到浏览器通知。
5. **P1 考试与作业记录**：新增/编辑考试、作业，标记作业完成状态。
6. **P2 手动微调**：对单节课程做增删改（覆盖导入产生的数据）。

## 4. 竞品简析

| 竞品 | 形态 | 与本产品的差异 |
|------|------|----------------|
| 超级课程表 | 手机 App，云端账号 | 依赖账号与云服务，数据不出本地不可实现 |
| 课程格子 | 手机 App，云端账号 | 同上 |
| 自建日历（Google/Apple 日历） | 通用日历 | 非课程专用，无法表达节次、单双周、考试作业等课程语义 |

结论：现有竞品均依赖云账号，无法满足「数据留在家中、免登录即用」的家庭自托管需求。本产品以课程语义建模 + 自托管为核心差异化。`[Assumption — 竞品信息基于公开认知，未做专项调研]`

### 5.2 课表浏览

**周视图（P0）**

布局：左侧为节次时间列，右侧 7 列对应周一至周日；每格放课程色块。顶部为周导航条（上一周 / 标题「第 N 周 · 9月2日–9月8日」/ 下一周 / 回到本周），右上角为「今天」与视图切换（周/日）。

交互逻辑：

- 打开应用默认进入当前周。切换周次后保持当前视图，不跳回。
- 点击课程块弹出课程详情（底部弹层在手机上、居中弹窗在电脑上），详情含课程全部字段与「编辑」「删除」按钮。
- 空白格点击可快捷新增该时段的课程（预填星期与节次）。
- 周次列头标注当前日期；手机端与桌面端均始终显示周一至周日 7 天。
- 周视图提供打印（打印样式适配 A4 横向）与导出 PNG 图片能力。

规则约束：

- 节次行高固定 `64px`（桌面）/ `56px`（手机），保证色块可读。
- 单双周课程：当前周为单周时只显示单周课程，双周同理；「全部周」课程始终显示。可在设置中关闭单双周过滤以显示全部。
- 课程色块显示课程名与地点；手机端宽度不足时只显示课程名。

异常情况：

- 课程跨节次（如 2–3 节）：合并单元格渲染。
- 两个课程时间重叠：后导入者向右错位半格显示，并在详情中标注冲突 `[Assumption — 采用错位显示，不做冲突拦截]`。
- 网络异常：显示骨架屏与重试按钮。

**日视图（P0）**

布局：按时间排序的卡片列表，每组课程下方挂接该课程的考试与作业摘要。顶部为日期导航（左右切换、今天）。

交互逻辑：点击卡片查看详情；点击考试/作业条目直接进入对应编辑弹窗。

### 5.3 课程管理

新增/编辑课程弹窗字段：

| 字段 | 类型 | 必填 | 约束 |
|------|------|------|------|
| 课程名称 | 文本 | 是 | 1–50 字 |
| 课程类型 | 单选 | 否 | 普通课 / 实验课，默认普通课；实验课在周课表中带「实验」标记 |
| 教师 | 文本 | 否 | 0–30 字 |
| 上课地点 | 文本 | 否 | 0–50 字 |
| 课程颜色 | 色板选择 | 否 | 从预设 8 色中选择；新课程按录入顺序从 8 色轮询分配，同课程名自动保持同色，可手动修改 |
| 周次 | 单选 | 是 | 全部周 / 单周 / 双周 / 自定义（如 1,3,5-8） |
| 星期 | 单选 | 是 | 周一至周日 |
| 起止节次 | 两个下拉 | 是 | 在当前学期节次行范围内选择，结束 ≥ 开始 |
| 备注 | 多行文本 | 否 | 0–200 字 |

交互逻辑：保存后立即刷新对应视图；删除需二次确认；新增课程保存成功后提供「继续新增下一门」快捷操作（表单保留，清空已保存字段，预填上一门课的部分常用字段如星期、地点），可连续录入多门课程；手动录入直接调用课程创建接口，不经过 PDF 课表解析与预览流程，与 PDF 导入互相独立。

### 5.4 节次时间模板

每个学期各自维护节次行，行数可增删、时间可编辑（格式 HH:mm，结束须晚于开始）。首次使用默认 12 节：08:00-08:45, 08:55-09:40, 10:00-10:45, 10:55-11:40, 14:00-14:45, 14:55-15:40, 16:00-16:45, 16:55-17:40, 19:00-19:45, 19:55-20:40, 20:50-21:35, 21:45-22:30。修改后课表与提醒即时生效。

### 5.5 PDF 课表导入

流程：课表页顶栏「导入课程」下拉选择「从 PDF 导入」→ 上传教务系统导出的课表 PDF → 前端自动解析 → 预览校验 → 确认导入；选择「手动录入」则打开课程编辑弹窗（见 5.3），与 PDF 导入互相独立。

PDF 解析规则（基于真实样本《严子辰(2026-2027-1)课表.pdf》解析得出，`[Data-backed]`）：

- 样表为 3 页 A4 横向（842×595pt）；第 1 页为课表主体，表头为「时间段 | 节次 | 星期一~星期日」，行分组为上午（节次 1-4）/ 下午（5-8）/ 晚上（9-10）共 10 节。
- 课程单元格字段以 `/` 分隔、`:` 键值，格式为「课程名（可带 ▲/● 标记）/ (开始-结束节)周次规则/场地:地点/教师:姓名/教学班:编号/教学班组成:班级列表/考核方式:XX/选课备注:/课程学时组成:讲课:N,实验:M/周学时:N/总学时:N/学分:N」。
- 周次规则形式：`1-16周`、`1-15周(单)`、`1-7周(单)`、`1-8周,10-16周(双)`、`1-10周,12周,15周`、`6-13周`。
- 课程类型判定：PDF 导入课程一律视为普通课（`[Data-backed]`，开发确认：教务 PDF 仅提示该课程含实验学时，不代表该节课是实验课；实验学时信息保留进备注），实验课由用户手动录入（见 5.3）。

解析出的课程字段：

| 字段 | 来源 |
|------|------|
| 课程名 | 单元格首段（去除 ▲/● 标记） |
| 教师 | 教师: 键值 |
| 地点 | 场地: 键值 |
| 星期 | 由所在列确定（星期一~星期日） |
| 起止节次 | 由所在行与 (开始-结束节) 区间确定 |
| 周次规则 | 展开为 weekType（全部/单/双/自定义）与周序号列表 |
| 课程类型 | 一律普通课（实验学时信息保留在备注；实验课手动录入） |

其他说明：

- 第 2 页底部含「实践课程：」「其他课程：」汇总行，导入时作为参考提示展示，不强制解析进课表 `[Expert judgment]`。
- 解析校验：解析失败或行校验失败时给出定位提示；预览页展示解析结果与错误统计。
- 导入时选择目标学期。导入模式：**追加**（保留现有课程）或 **覆盖**（仅清空目标学期课程后导入）；覆盖模式不清除该学期已有考试与作业，仅将关联课程置空。导入前提示影响范围。
- 支持多份 PDF 分次上传追加 `[Expert judgment]`。

### 5.6 课程提醒

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用提醒 | 关 | 总开关；设置页首次使用时引导开启 |
| 提醒时机 | 上课前 10 分钟 | 每节课提醒；或仅当天首课提醒 |
| 提前分钟数 | 10 | 5/10/15/30 可选 |
| 实验课提醒 | 关 | 独立开关，默认关闭；仅对课程类型=实验课的课程生效，与普通课程提醒互不影响 |
| 作业截止提醒 | 关 | 可选项，默认关闭，可在设置中开启 |

实现约定（单用户、无推送服务）：浏览器打开页面时检测当天课程，在到达提醒时间后弹出浏览器通知（需用户授权）+ 站内铃铛提示；页面未打开时不产生提醒。`[Assumption — 不做服务端推送，浏览器通知即可满足家庭场景]`

站内提醒入口：桌面端为顶栏铃铛图标（带未读角标），移动端并入日课表页摘要条；提醒内容含上课提醒与作业截止提醒，点击跳转对应详情。

### 5.7 考试、实验与作业分类列表

考试列表与作业列表均按时间倒序排列，考试用橙色标签、作业用蓝色标签区分。作业支持在列表中直接切换完成状态（带勾选交互与完成划线）。编辑入口：课程详情弹窗内的「考试/作业」Tab，以及主页面右上角的独立入口。

考试页内提供三个子 Tab 分类列表（事项分类列表）：

- **考试**：全部考试记录，按时间倒序，橙色标签。
- **实验**：课程类型=实验课的课程列表（显示课程名、教师、地点、星期与节次），按星期与节次排序；从该列表可点入课程详情或直接新增实验课课程。
- **作业**：全部作业记录，按时间倒序，蓝色标签，支持勾选完成。

三个子 Tab 各自提供「新增」入口与筛选（作业含完成状态筛选），数据均按当前学期展示。

### 5.8 学期管理

- 支持创建、编辑、删除多个学期，每学期独立起止日期与每周起始日（默认周一）；当前学期由用户手动切换。删除当前学期时自动切换到剩余学期中起始日期最近的一个；无学期时课表显示新建学期引导。
- 当前周次 = 基于当前学期起始日与当前日期的周差 + 1；超出学期范围时显示「假期」提示，课表置灰。
- 单双周判定：以当前周序号奇偶为准。

### 5.9 数据备份

「设置 → 数据管理」提供「导出 JSON」与「导入 JSON」。导出文件含全部课程、节次模板、学期、考试、作业、设置。导入支持覆盖当前数据。

### 5.10 访问控制（可选）

默认关闭，可在设置页开启（4–20 位口令）。开启后，未认证会话进入应用前需输入口令；口令页为全屏居中卡片（品牌 logo + 口令输入 + 确认）。口令哈希存储于本地数据库。无找回机制，忘记需手工重置。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 响应式 | 手机竖屏（≥360px）、平板、桌面（≥1280px）三种断点下功能完整可用；手机横屏（≥768px）自然切换平板布局，无锁定 |

| 浏览器兼容 | Chrome / Edge / Safari 最近两个大版本 |
| PWA | 提供 Web App Manifest 与图标，支持添加到主屏幕全屏打开；不做离线缓存 |

| M2 增强 | 课程提醒、访问口令 | M1 |

团队依赖：单人或小团队；无外部供应商。技术依赖见《技术设计文档》。

## 8. 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 正方教务系统各版本 PDF 布局略有差异 | 高 | 中 | 基于真实样本适配解析规则；解析预览可人工修正；多版本适配延后 |
| 浏览器通知权限被关闭导致提醒失效 | 中 | 低 | 站内铃铛兜底，设置页提示授权状态 |
| NAS 环境差异（架构/时区/端口冲突） | 中 | 中 | 提供多架构镜像、时区环境变量、端口可配置，部署文档覆盖常见 NAS |
| 单用户误操作覆盖数据 | 低 | 高 | 导入覆盖前二次确认；提供 JSON 导出备份习惯引导 |

## 9. 验收标准

| # | 场景 | 通过标准 |
|---|------|----------|
| 1 | 首次导入 | 新用户 15 分钟内完成「上传教务系统 PDF → 自动解析 → 预览校验 → 确认导入」，周视图正确展示 |
| 2 | 单双周 | 单周/双周/全部周课程按当前周正确显隐 |
| 3 | 手机访问 | 手机浏览器打开即见当日安排，日视图可用，课程详情可编辑 |
| 4 | 提醒 | 设置上课前 10 分钟提醒并授权通知后，到点收到浏览器通知 |
| 5 | 备份恢复 | 导出 JSON 后可导入恢复，数据完整一致 |
| 6 | Docker 部署 | 按部署文档执行后，容器启动成功，数据写入挂载卷，重启容器数据不丢失 |
| 7 | 多学期 | 创建两个学期并切换，两个学期的课程/考试/作业数据互不干扰，删除学期后其数据全部清除 |
| 8 | 实验课 | 新增实验课课程后，周课表色块带「实验」标记；考试页内「实验」子 Tab 正确列出该实验课；开启实验课提醒后到点收到通知，关闭课程提醒不影响实验课提醒 |
| 9 | PDF 解析 | 上传真实正方教务系统导出 PDF（如严子辰课表）可正确解析全部课程，单双周、跨节次、实验课识别正确 |
