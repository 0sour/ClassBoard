> 本文件记录 ClassBoard 项目从立项至今的全部对话与开发过程，供跨天续接、回溯决策。
> 更新：每次会话后追加「会话记录」章节。

---

## 一、项目概述

- **产品**：ClassBoard 课程表 Web 应用（自托管，适配电脑与手机浏览器）
- **定位**：单用户家庭使用；课程数据以 Excel 导入为主、手动微调为辅；支持课程提醒、考试与作业记录、数据导出备份
- **技术栈**：后端 Node.js + Express + better-sqlite3（SQLite WAL）；前端 Vue 3 + Vite；单容器 Docker 部署，前端构建产物由后端静态托管，同源 `/api`
- **文档**：`docs/01-PRD`、`02-技术设计`、`03-设计语言`、`04-UI设计`、`05-UI组件参考.html`
