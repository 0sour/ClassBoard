> 本文件记录 ClassBoard 项目从立项至今的全部对话与开发过程，供跨天续接、回溯决策。

---

## 一、项目概述

- **产品**：ClassBoard 课程表 Web 应用（自托管，适配电脑与手机浏览器）
- **定位**：单用户家庭使用；课程数据以 Excel 导入为主、手动微调为辅；支持课程提醒、考试与作业记录、数据导出备份
- **技术栈**：后端 Node.js + Express + better-sqlite3（SQLite WAL）；前端 Vue 3 + Vite；单容器 Docker 部署，前端构建产物由后端静态托管，同源 `/api`
- **文档**：`docs/01-PRD`、`02-技术设计`、`03-设计语言`、`04-UI设计`、`05-UI组件参考.html`

## 六、关键约定

- 下拉选择一律用自研 `AppSelect`，不使用原生 `<select>`（文档 4.9；外部关闭为文档级 mousedown 监听，无遮罩）
- PDF 导入课程一律视为理论课；实验课手动录入
- 周序号算法 `calcWeekNumber`、单双周过滤 `isCourseVisible`（`server/lib/week.js`）
- 课程冲突错位显示：同日同节次重叠时 id 大者右移半格 + 黄色冲突点标记（`computeOverlapGroups`）；不做冲突拦截
- 无当前学期时 `/api/schedule` 的 courses/exams/homework 均返回空数组（weekNumber=null）
- 视觉基准：清新浅色极简（设计语言文档 v2.0），本期无暗色模式
