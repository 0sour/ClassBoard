## 1. 设计原则

1. **信息密度优先**：课表本质是高频查阅工具。课程色块必须一眼可辨，次要信息（教师、地点）弱化展示。
2. **移动端优先**：手机竖屏是最高频场景，默认日视图、大触控目标（≥44px）；桌面端放大信息密度，默认周视图。
3. **颜色即语义**：每门课程一个主题色；考试、作业、提醒分别用橙、蓝、绿语义色，全应用统一。
4. **浅色极简**：近白背景、单一主蓝点缀、大留白、纤细边框、柔和分层阴影。界面安静、克制、不打扰，长时间使用不疲劳。
5. **课程色块柔和化**：课程色块不使用高饱和实心底色，改用「浅色底 + 同色系描边 + 深色文字」，在大面积网格中保持可读且不刺眼。

## 2. 命名规范

所有 token 使用 `kebab-case`，同时满足 CSS 自定义属性名与 JavaScript 对象键合法要求。

| 类别 | 模式 | 示例 |
|------|------|------|
| 颜色（视觉层） | `color-{role}-{shade}` | `color-primary-500` |
| 颜色（语义层） | `color-{semantic-role}` | `color-brand` |
| 课程色板 | `course-{n}` | `course-1` ~ `course-8` |
| 间距 | `spacing-{size}` | `spacing-md` |
| 字号 | `font-size-{scale}` | `font-size-md` |
| 字重 | `font-weight-{name}` | `font-weight-medium` |
| 行高 | `line-height-{scale}` | `line-height-normal` |
| 圆角 | `radius-{size}` | `radius-md` |
| 阴影 | `shadow-{level}` | `shadow-card` |
| 动效 | `motion-duration-{speed}` / `motion-easing-{name}` | `motion-duration-normal` |
| 层级 | `z-index-{layer}` | `z-index-modal` |
| 组件前缀 | `{component}-{property}` | `btn-bg` |

## 7. 动效

| Token | 值 | 用途 |
|-------|-----|------|
| `motion-duration-fast` | `150ms` | 图标按钮悬停、关闭按钮 |
| `motion-duration-normal` | `180ms` | 分段切换、导航按钮、色块悬停 |
| `motion-duration-slow` | `220ms` | 弹窗 pop 动画 |
| `motion-duration-reveal` | `500ms` | 页面元素入场 |
| `motion-easing-standard` | `cubic-bezier(.2,.7,.2,1)` | 标准曲线 |
| `motion-easing-spring` | `cubic-bezier(.2,.7,.2,1)` | 弹窗 pop（含微缩放位移）；v2.1 注：与标准曲线同值，§10 输出仅保留 `motion-easing-standard`，组件一律引用 standard |

入场动画：元素从 `translateY(8px)` + `opacity 0` 过渡到正常位（`fadeUp`），分批次用 `animation-delay`（30ms / 90ms / 140ms / 190ms / 240ms / 300ms）错峰。规则：所有动效 ≤ 500ms；尊重系统 `prefers-reduced-motion`，开启时关闭全部动画与过渡。

## 9. 断点

| 断点 | 区间 | 布局策略 |
|------|------|----------|
| `bp-mobile` | `< 768px` | 单列；周课表为单日视图（顶部日期轮盘选日 + 当天课程列表，日期格 56px）；顶栏压缩（学期限宽、导入图标化） |
| `bp-tablet` | `768px – 1279px` | 单列 + 信息面板折为三列排布（每行 52px） |
| `bp-desktop` | `≥ 1280px` | 双栏：主课表 + 右侧 296px 信息面板（每行 64px）；最大内容宽 1440px |

页面最大内容宽 1440px，居中。顶栏高度：桌面 60px、移动 56px。

## 11. 暗色模式（本期不做）

清新浅色极简风格以浅色为唯一基调，v2.0 明确不提供暗色模式，`color-scheme: light` 锁定。若后续家庭场景需要夜间护眼模式，在独立里程碑评估，届时基于同一套语义 token 增加 `[data-theme='dark']` 覆盖层，不改变组件代码结构。`[Assumption — 本期范围外]`

## 12. 无障碍

| 项 | 要求 |
|----|------|
| 对比度 | 正文（`color-text-body` #1f2933 于 #f6f7f9/#ffffff）≥ 7:1；课程色块文字 ≥ 7:1；主按钮白字于 #3b82f6 ≥ 4.5:1（WCAG 2.1 AA/AAA） |
| 焦点 | `:focus-visible` 2px 主色描边 + 2px 偏移；键盘可完整操作 |
| 语义 | 弹窗 `role="dialog"` + `aria-modal`；分段控件 `role="tablist"` / `role="tab"` / `aria-selected`；轻提示 `role="status"`；加载中 `aria-busy` |
| 触控 | 移动端可点目标 ≥ 44×44px |
| 动效 | 响应 `prefers-reduced-motion`，关闭全部动画 |
| 课程色块 | 不只靠颜色区分课程，色块内恒显示课程名文本（`aria-label` 同步） |

统一线性图标，24×24 viewBox、1.75px 描边、`currentColor` 继承、`stroke-linecap/join: round`。仅使用课程表场景所需图标：周视图/日视图、日历、时钟、加号、铅笔、垃圾桶、关闭、箭头（上/下/左/右）、铃铛、下载、上传、齿轮、搜索、勾选、更多（· · ·）、用户、地点、循环（单双周）、刷新、文件。
